    Rough-in decides whether the finish goes smoothly. The carrier, 2 inch waste, 3/4 inch supply and vent all go in to the spec sheet before drywall. The rough gets inspected before cover. Then the walls close.

    Sloan Flush Valve Installation in Muskogee, OK

    Sloan Royal valves are on most commercial urinals we see. Each Sloan Royal gets the right inside parts for the bowl, a tuned control stop and a rebuild kit on hand. Sensor versions mount the same way. Battery models need no wiring.

    Urinal Installation Cost Factors in Muskogee, OK

    Carrier work is the biggest cost swing. A replacement on an existing carrier with good supply and drain lines costs far less than a new install that needs a carrier, a new 2 inch drain and a 3/4 inch supply run through finished walls. Sensor valves add a few hundred. We itemize each piece.

    Flush Valve Urinal Installation in Muskogee, OK

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. The volume matches the fixture rating. Wrong settings stain bowls.

    Home Gym and Garage Urinals in Muskogee, OK

    Waterless Urinal Installation in Muskogee

    Waterless urinals save the most water and need the most discipline. They use a cartridge or a layer of sealing liquid that lets urine pass while blocking sewer gas, and the cartridge has to be swapped on schedule or the restroom starts to smell. Cleaning staff need a quick lesson. We show them how.
