    How We Install Kitchen Sinks in Muskogee, OK: Style by Style

    New Construction Sink Rough-In in Muskogee, OK

    Rough-in sets the drain height and the stops long before the cabinets arrive.     Undermount Sink Installation in Muskogee, OK

    Undermounts hang from clips anchored into the underside of the stone, plus a bead of silicone along the rim. We support the bowl from below with a brace while the silicone cures, typically for a full day, before loading it with water. Rushing this causes the classic sag. Just an eighth of an inch of sag leaves a gap that catches water and food along the edge.

    Disposal and Dishwasher Hookup with Sink Installation in Muskogee, OK

    Most new kitchen sinks get paired with a disposal and a dishwasher. We mount the disposal, run the dishwasher drain through an air gap or high loop and install a dedicated hot supply with its own shutoff. Doing it all at once saves money. We test it all the way you will use it.

    Stainless Sinks With Sound Pads in Muskogee

    Cheap stainless bowls are noisy when dishes hit them or the disposal runs. Better sinks come with rubber pads and an undercoating, and if yours does not, we can add a coat of spray undercoating before we set it. It is a small thing. Once the bowl is mounted, the space underneath is hard to reach, so this is a job worth doing while the sink is still on the floor.

    Emergency Sink Replacement in Muskogee

    A cracked bowl or a rusted-through strainer can flood a cabinet within hours. First, close both angle stops and stop using the sink. We carry common sizes. If you have a standard 33 by 22 inch drop-in, we can usually remove the damaged sink and set a new one that day.

    Farmhouse Sink Installation in Muskogee, OK

    A fireclay apron sink sits on a frame inside the cabinet, not on the countertop.     Drop-In Sink Replacement in Muskogee

    Pulling an old drop-in starts with cutting the caulk line and backing off the clips from below. Old clips are often rusted solid, so we bring a reciprocating saw and cut them off rather than prying on the counter. Laminate chips if you pry. Your new rim has to fully cover the old hole.
