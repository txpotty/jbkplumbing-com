    Double Check Valve Assembly Installation in Tulsa

    Double check assemblies work for low-hazard connections such as many fire lines and some irrigation. Two spring-loaded checks and four test cocks are inside, and since they do not discharge water, they can go in a vault or below grade where local rules allow, sized so the pressure loss stays small. We size for flow.

    Reduced Pressure Zone (RPZ) Device Installation in Tulsa, OK

    High-hazard connections in Tulsa, OK call for a reduced pressure zone assembly. Think chemical injection or medical equipment, where a backflow event could put something toxic in the supply, so the RPZ adds a relief valve between two checks that dumps water if either check leaks. It has to drain somewhere.

    Backflow Preventer Installation Cost Comparison in Tulsa, OK

    Backflow Enclosures and Freeze Protection in Tulsa, OK

    Above-ground assemblies bake in summer sun and can freeze on a cold night.     Reduced Pressure Zone (RPZ) Assembly Installation in Tulsa

    Two independent checks and a relief valve make up an RPZ. If the zone between the checks loses its pressure margin, the relief valve opens, dumping water to the floor or a drain so nothing can pass upstream, which is why we never bury one in a pit in Tulsa. We install Watts and Febco units.
